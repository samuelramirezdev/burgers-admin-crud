# 🍔 Panel de Administración y Control de Inventario — Burgers & Co.

Sistema de gestión interna (CRUD) desarrollado para administrar el menú, controlar el stock e inventario y calcular el valor comercial en tiempo real del restaurante **Burgers & Co.**

## 🌐 Demo en Vivo
Puedes probar la aplicación interactiva desplegada en GitHub Pages:  
👉 https://samuelramirezdev.github.io/burgers-admin-crud/

## 🚀 Funcionalidades Principales
* **Operaciones CRUD Completas:** Permitir **C**rear, **L**eer, **A**ctualizar y **E**liminar productos del menú.
* **Persistencia de Datos (`localStorage`):** Guarda las modificaciones localmente para mantener la información al recargar la página.
* **Métricas en Tiempo Real:** Panel superior que calcula automáticamente el total de productos en menú y el valor total del inventario disponible.
* **Búsqueda Dinámica:** Filtro en tiempo real para encontrar productos por nombre o categoría.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica con tablas y formularios interactivos.
* **CSS3:** Diseño oscuro con acentos cálidos adaptado a la identidad de la marca.
* **JavaScript (Vanilla ES6+):** Manipulación del DOM, lógica de arrays/objetos, manejo de `localStorage` y cálculo de métricas.
